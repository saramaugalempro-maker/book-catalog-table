# Book Catalog Table

A semantic HTML table displaying information about a selection of books, built as part of the **freeCodeCamp Responsive Web Design** curriculum.

## About

This project is a book catalog created using semantic HTML table elements. It displays each book's title, author, genre, and publication year.

The table also includes a footer showing the total number of books.

## Features

* Book catalog table
* Table header with column titles
* Five books displayed in the table
* Book title, author, genre, and publication year
* Table footer with the total number of books
* Column spanning with `colspan`

## HTML Concepts Practiced

* `<table>`
* `<thead>`
* `<tbody>`
* `<tfoot>`
* `<tr>`
* `<th>`
* `<td>`
* `<caption>`
* `colspan`
